# Contributing

WINCH is public source, but the initial project maintains a single-author provenance boundary.

- Bug reports, reproduction cases, design discussion, and security reports are welcome.
- Code, documentation, generated assets, and dependency-vendoring pull requests are not accepted unless Bobtoshi explicitly opens a contribution round.
- Do not submit copied, scraped, generated, or third-party code as if it were original.
- Security issues must follow `SECURITY.md`, not a public issue.

This policy keeps the canonical tree's authorship and licensing record unambiguous. Forks remain permitted under the AGPL-3.0-only license and must preserve applicable notices.
